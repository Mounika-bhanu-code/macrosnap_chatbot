# MacroSnap 🍎

**MacroSnap** is an AI-powered nutrition assistant that helps users estimate calories and macronutrients from food photos or text descriptions using Google Gemini AI.

## ✨ Features

* 📸 **Food Photo Analysis:** Upload a meal photo to estimate its nutritional values.
* 🥗 **Nutrition Estimation:** Get estimated calories, protein, carbohydrates, and fats.
* 💬 **AI Chat Assistant:** Ask questions about meals and nutrition.
* 📲 **WhatsApp Integration:** Send nutrition summaries through WhatsApp using Twilio.

## 🛠️ Tech Stack

* Python
* Streamlit
* Google Gemini API
* Twilio WhatsApp API

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Mounika-bhanu-code/macrosnap.git
cd macrosnap
```

### 2. Create and activate a virtual environment

```bash
python -m venv venv
```

**Windows:**

```bash
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure API keys

Set up your Google Gemini API key and Twilio credentials securely using environment variables or Streamlit secrets. **Never upload API keys or secret credentials to GitHub.**

### 5. Run the application

```bash
streamlit run app.py
```

The application will open in your browser, usually at `http://localhost:8501`.

## ⚠️ Disclaimer

Nutrition values generated by AI are estimates and may not be exact. They should not replace professional dietary advice.
